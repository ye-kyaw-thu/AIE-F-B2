# Assignment-6

မြန်မာစာကြောင်းတွေနဲ့ ဟိအဲရိုး (အင်္ဂလိပ် transliteration) အကြား ဘာသာပြန်ကြရအောင်။  

- Neural Machine Translation framewok ကိုတော့ ဆရာကိုယ်တိုင် အတန်းထဲမှာ လက်တွေ့ tutorial လုပ်ပြထားတဲ့ Marian framework ကိုပဲ သုံးကြရအောင်။
- Myanmar to Hiero, Hiero to Myanmar နှစ်မျိုးစလုံး ဘာသာပြန်ပါ
- Architecture အနေနဲ့က Sequence-to-Sequence ရော Transformer နှစ်မျိုး အနည်းဆုံး သုံးကြည့်ပါ။
- ထပ်ဖြည့်နိုင်တဲ့ သူကတော့ Marian က suport လုပ်တဲ့ ensemble approach ကိုလည်း လုပ်ကြည့်ကြပါ။  
- ရလဒ်ကို အကောင်းဆုံးရအောင် hyperparameter tuning လုပ်ကြည့်ကြပါ။
- ဒီတစ်ခါတော့ Group work အနေနဲ့ မသွားကြပဲ တစ်ယောက်ချင်းစီ လုပ်ပြီး တင်ကြပါ။
